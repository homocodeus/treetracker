02 / MODEL TRAINING

Train a model to recognize your tree.

Export your annotation ZIP and extract it into the exported folder. Run the following commands in a terminal from the project folder.

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python pipeline.py prepare exported --output dataset
python pipeline.py train --data dataset/dataset.yaml --epochs 100 --device cpu

For macOS, use --device mps, for a CUDA GPU, use --device 0 Model weights are downloaded on the first training run. The trained model path is printed in the terminal; usually runs/tree-pose/weights/best.pt.

Use images from separate recording sessions for validation. Randomly splitting similar consecutive frames can overestimate performance. Review the automatic split before training.

03 / MOTION ANALYSIS

Measure inclination and movement direction in video.

Use a trained model, the matching keypoint schema and a fixed-camera video of a single tree.

python pipeline.py analyze --model runs/tree-pose/weights/best.pt --video tree.mp4 --schema dataset/schema.json --output analysis
annotated.mp4

Video with keypoints, connections and angle changes overlaid.

motion.csv

Time, position, pixel displacement, direction and angle change.

summary.json

Analysis details and the reference schema.

Each point or segment uses its first confident detection as the reference. Angles are measured from upward vertical, clockwise positive. Movement is measured in the image plane, not in centimeters or depth. Camera movement is not compensated.
